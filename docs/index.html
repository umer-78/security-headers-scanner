Grades: A ≥ 90, B ≥ 80, C ≥ 65, D ≥ 50, else F.

What it checks

  • HTTPS in use · HSTS (max-age ≥ 180 days)
  • CSP: present, no bare unsafe-inline, no wildcard script hosts
  • X-Content-Type-Options: nosniff
  • Clickjacking: XFO or CSP frame-ancestors
  • Referrer-Policy, Permissions-Policy
  • Version numbers in Server / X-Powered-By
  • Cookies: Secure, HttpOnly, SameSite

The CLI sends one GET per URL — only scan sites you own or have permission to test.
